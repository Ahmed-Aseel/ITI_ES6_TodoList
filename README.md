# 📝 To-Do List App

A simple, responsive and fully functional To-Do List application built using **TypeScript**, **HTML**, **Bootstrap**, and **Local Storage**. Tasks can be added, updated, marked as complete, or deleted — all with input validation and persistent data storage.

---

## 🚀 Features

- ✅ **Add new tasks** with title and description
- ✏️ **Edit existing tasks**
- ✔️ **Mark tasks as completed**
- 🗑️ **Delete tasks**
- 🎯 **Real-time validation** for title and description with visual feedback
- 💾 **Data persistence** using `localStorage`
- 🎨 **Responsive UI** with Bootstrap styling
- 🔒 **Prevent** editing or deleting completed tasks
- 🔍 **Clear** empty state message when there are no tasks

---

## 🧪 Validation Rules

- **Title**: 1–50 characters, must start with a letter. Allowed: letters, numbers, spaces.
- **Description**: 1–200 characters, must start with a letter. Allowed: letters, numbers, spaces, and `. , ! ?`
